# Text-to-SQL AI — Python Dependencies
#
# All versions are pinned to the exact versions confirmed working
# with Python 3.11.7 on Windows (CPU-only).
#
# Standard install (all dependencies except PyTorch):
#   pip install -r requirements.txt
#
# PyTorch must be installed separately because the CPU-only build
# is not on PyPI — it is served from the PyTorch wheel index:
#   pip install torch==2.2.2+cpu --index-url https://download.pytorch.org/whl/cpu
#
# Full fresh-install sequence (Windows PowerShell):
#   python -m venv venv
#   venv\Scripts\activate
#   pip install torch==2.2.2+cpu --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
#
# To update a dependency:
#   1. Change the version pin below
#   2. Re-run the install sequence above
#   3. Run:  python -m pytest --tb=no -q
#   4. Verify the application works manually
